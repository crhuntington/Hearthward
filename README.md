# Hearthward

Post-sale engagement platform connecting real estate agents, mortgage lenders, and homeowners.

## Structure

- `app/index.html` — Multi-portal app prototype (homeowner app, agent portal, lender portal, admin). Open the file and use the demo login buttons.
- `website/index.html` — Marketing website (Home, For Agents, For Lenders, For Homeowners, About).

Both are single self-contained HTML files — no build step or dependencies.

## Run locally

Open either `index.html` in a browser.

## Deploy with GitHub Pages

Settings → Pages → Deploy from branch → `main` / root. The site will be at
`https://<username>.github.io/<repo>/website/` and the app at `/app/`.
